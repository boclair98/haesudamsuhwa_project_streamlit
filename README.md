# RO Lens

### 기록을 더 정확하게, 탐색은 더 깊게.

2021년 천수만 원수 관측자료와 RO 샘플 공정 기록을 연결해
1단 인입압력과 비에너지소비량(SEC)을 탐색하는 Streamlit 데이터 앱입니다.
실제 플랜트 제어 화면이 아니라, 기록·모델·한계를 한 화면에서 확인하는
재현 가능한 연구용 데모를 목표로 합니다.

[서비스 열기 →](https://haesudamsuhwa.coders.kr/) · [검증 보고서](VERIFICATION.md)

> **중요**  이 저장소와 공개 서비스는 실제 센서·PLC·SCADA·제어 밸브와 연결되지 않습니다.
> 표시값은 과거 기록과 저장 모델의 분석 결과이며, 안전·식수 적합성·규제 준수·운전 전환을
> 판정하거나 운전 설정값을 권고하지 않습니다.

## RO Lens가 제공하는 경험

1. 기록 범위 확인 | 2. 시점 탐색 | 3. 월간 비교 | 4. 조건 실험 | 5. 검토 후보 복기
--- | --- | --- | --- | ---
2021년 기록 기간과 표본 수 확인 | 실제 존재하는 날짜·시각 선택 | 임의의 두 달 지표 비교 | 입력값을 기록 범위 안에서 조절 | 원자료·센서·운영 로그와 함께 후보 점검

앱의 흐름은 다음과 같습니다.

```text
정제된 원수·RO 기록 로딩
        ↓
압력 모델 추정 (수온, pH)
        ↓
SEC 모델 추정 (원수 수질 + 추정 압력)
        ↓
기록값·추정값·차이 계산
        ↓
스냅샷 / 월간 비교 / 시나리오 / 검토 후보 시각화
```

## 화면별 사용법

### 01. 운전 스냅샷

날짜와 실제 기록 시각을 고르면 다음 정보를 한 화면에서 보여줍니다.

- 1단 인입압력·SEC의 기록값과 모델 추정값
- 선택 SEC가 전체 기록에서 차지하는 백분위 위치
- 원수 → 전처리 → 1단 RO → 2단 RO → 생산수 흐름
- 선택 시점 전후 24시간 SEC 추이와 원수 조건

### 02. 기간 성과

월평균은 생산량 가중치가 없는 단순 평균입니다. 분석 월과 비교 월을 직접 선택해
압력·SEC·최종 TDS의 차이를 확인하고, 월별 표본 수와 정시 관측 밀도로 희소한 기간을 구분합니다.

### 03. 예측 실험실

수온, pH, 탁도, COD, 총질소, 총인을 기록 범위 안에서 조절합니다. 압력 모델의 결과가
SEC 모델의 입력으로 이어지는 chained prediction 구조이며, 기준값은 각 변수의 기록 중앙값입니다.

### 04. 운영 인사이트

압력 오차와 SEC 오차의 절대값이 각각 전체 기록의 95백분위 이상인 시점을 검토 후보로 표시합니다.
이 기준은 현재 데이터 분포에서 계산되며, 품질 이상이나 안전 상태를 의미하지 않습니다.
후보는 시간순 차트와 표로 확인하고 CSV로 내려받을 수 있습니다.

### 05. 데이터·모델 카드

공식 출처가 문서화된 원수 관측자료와 출처가 충분히 문서화되지 않은 RO 샘플 공정 기록을
분리해 설명합니다. 결측 제거·중복 제거·0값 분포·모델 입력 범위·누락 변수를 함께 공개합니다.

## 데이터·모델 계약

### 데이터 현황

항목 | 값
--- | ---
원본 행 | 5,687건
사용 가능 행 | 5,686건
기록 기간 | 2021-01-01 — 2021-12-16
정제 규칙 | 날짜·수치 변환 → 필수값 결측 제거 → 동일 시각 중복은 마지막 기록 유지
원수 변수 | 수온, pH, 탁도, COD, 총질소, 총인
RO 기록 변수 | 1·2단 압력, 1·2단 TDS, SEC

원수 변수는 저장소 파일명 기준 해양환경공단 해양수질자동측정망 천수만(2021) 자료입니다.
RO 압력·TDS·SEC는 측정 설비, 보정 방법, 생산량 가중치가 저장소에 충분히 문서화되지 않은
샘플/가공 공정 기록으로 취급합니다.

### 모델 입력과 성능

모델 | 입력 | 출력
--- | --- | ---
압력 선형회귀 | 수온, pH | 1단 인입압력
SEC 랜덤포레스트 | 총인, COD, 총질소, 탁도, **추정** 1단 인입압력 | SEC(kWh/m³)

화면의 MAE·RMSE·R²는 저장 모델을 전체 공정 기록에 다시 적용한 적합도입니다.
독립 시간순 검증이나 학습 파이프라인이 저장소에 없으므로 일반화 성능으로 해석하면 안 됩니다.
모델 파일은 `models/manifest.json`의 SHA-256 매니페스트를 통과한 경우에만 로드합니다.

## 빠른 실행

```bash
git clone https://github.com/boclair98/haesudamsuhwa_project_streamlit.git
cd haesudamsuhwa_project_streamlit

python -m venv .venv
# macOS/Linux: source .venv/bin/activate
# Windows:    .venv\Scripts\activate

python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`을 엽니다. Streamlit 헬스 엔드포인트는
`http://localhost:8501/_stcore/health`입니다.

## 검증

```bash
python -m unittest discover -s tests -v
python -m py_compile app.py desalination/*.py
```

현재 자동 테스트는 데이터 정제, 모델 무결성, 24행 chained prediction, 월간 집계,
95백분위 검토 후보를 포함합니다. 실행 결과와 브라우저 검증 항목은
[`VERIFICATION.md`](VERIFICATION.md)에 기록합니다.

## 배포

`coders.yaml`은 Streamlit WebSocket을 보존하는 `standalone` 모드, 공개 포트 8501,
세션 타임아웃 3600초를 사용합니다. Docker 컨테이너는 플랫폼이 주입하는 `PORT`에
`0.0.0.0`으로 바인딩합니다.

공개 데모: [haesudamsuhwa.coders.kr](https://haesudamsuhwa.coders.kr/)

## 알려진 한계

- 실시간 센서, PLC, SCADA, 유량계, 제어 밸브와 연결되지 않습니다.
- 염분·전기전도도, 원수/생산수 유량, 회수율, 막 상태, 차압, 약품 주입량이 모델에 없습니다.
- 생산량·회수율·식수 적합성·규제 준수·막 세정·운전 모드 전환을 계산하거나 판정하지 않습니다.
- 데이터의 0값이 실제 측정값인지 결측 대체값인지 원자료만으로 확정할 수 없습니다.
- 검토 후보는 통계적 데이터 점검 순서이며, 알람이나 운전 권고가 아닙니다.

추가 학습 파이프라인, 시간순 독립 검증, 실제 센서 연동이 필요하다면 별도 운영 설계와
데이터 계약을 먼저 수립해야 합니다.
