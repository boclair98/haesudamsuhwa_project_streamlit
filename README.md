# haesudamsuhwa_project_streamlit

RO 해수담수화 공정 데이터를 분석하고, 전력 사용량과 공정 상태를 예측해 시각화하는 Streamlit 기반 대시보드 프로젝트입니다.

수질 데이터와 RO 공정 데이터를 활용해 인입압력과 전력량을 예측하고, 운영자가 공정 상태를 직관적으로 확인할 수 있도록 실시간 대시보드, 생산관리, 수질 분석 화면을 구성했습니다.

## 프로젝트 배경

해수담수화 공정은 수질과 운전 조건에 따라 필요한 전력량이 달라집니다. 고정된 전력 기준으로 운영하면 에너지 낭비와 비용 증가가 발생할 수 있기 때문에, 수질 데이터를 기반으로 전력 사용량을 예측하고 공정 상태를 시각화하는 도구를 만들었습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 실시간 대시보드 | 수온, pH 등 입력값을 기반으로 인입압력과 전력량을 예측합니다. |
| 상태 시각화 | 예측 결과에 따라 정상, 주의, 경고 상태를 이미지와 지표로 표시합니다. |
| 생산관리 | 월별 RO 공정 데이터를 비교하고 전력량 변화 추이를 확인합니다. |
| 수질 분석 | 수온, 탁도, 총인, 총질소, COD 등 수질 지표를 시각화합니다. |
| 예측 시뮬레이터 | 사용자 입력값을 변경하며 예상 압력과 전력량 변화를 확인합니다. |

## 실행 방법

```bash

pip install -r requirements.txt
streamlit run app.py
```

```text

  -> 압력 예측
```

## 배운 점

- 공공/공정 데이터를 분석 가능한 형태로 정제하는 과정을 경험했습니다.
- 단순 모델 성능보다 데이터 품질과 변수 선택이 중요하다는 점을 확인했습니다.
- 예측 결과를 운영자가 이해할 수 있는 대시보드 형태로 표현했습니다.
- Streamlit을 활용해 데이터 분석 결과를 웹 서비스처럼 빠르게 배포하는 흐름을 익혔습니다.
